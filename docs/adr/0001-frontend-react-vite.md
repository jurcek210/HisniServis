# Izbira tehnologij za frontend: React in Vite

## Kontekst in opredelitev problema

Aplikacija HišniServis potrebuje uporabniški vmesnik, ki stanovalcem omogoča objavljanje popravil in primerjavo ponudb, izvajalcem pa pregled popravil in oddajo ponudb. Uporabniški vmesnik mora biti pregleden, odziven in enostaven za nadaljnji razvoj. Zato je treba izbrati tehnologiji za izdelavo frontenda in razvojno okolje.

## Obravnavane možnosti

* React z razvojnim okoljem Vite.
* Vue z razvojnim okoljem Vite.
* Angular z ustreznim razvojnim okoljem.

## Izid odločitve

Izbrana možnost: »React in Vite«, ker React omogoča izdelavo ponovno uporabljivih komponent uporabniškega vmesnika, Vite pa zagotavlja hitro razvojno okolje in preprosto konfiguracijo projekta.

### Posledice

* Dobro, ker lahko uporabniški vmesnik razdelimo na manjše in ponovno uporabljive komponente.
* Dobro, ker Vite omogoča hiter zagon razvojnega strežnika in hitro osveževanje sprememb.
* Dobro, ker je mogoče posamezne dele uporabniškega vmesnika razvijati in testirati ločeno.
* Slabo, ker je treba ustrezno izbrati in vzdrževati dodatne knjižnice za usmerjanje, obrazce in druge funkcionalnosti.
* Slabo, ker je za pravilno strukturo aplikacije treba dosledno organizirati komponente in njihovo stanje.
